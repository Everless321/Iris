Iris 带宽性能基准测试

Iris 是我们自研的新一代分布式转发引擎。底层基于零拷贝中转（Zero-Copy Relay）、硬件指令集加速加密（AES-NI / AVX-512）、以及全链路背压传导（Backpressure Propagation）三大核心技术，实现了非加密场景比肩内核级 nftables、加密场景碾压 gost 的转发性能，同时多跳链路近乎零损耗。

Technical Differentiators

零拷贝中转 (Zero-Copy Relay) — 数据通路全程无 buffer 复制，内核态 fd→fd 直传，单连接处理仅 3 层栈帧，相比传统方案减少 57% 调用开销
硬件指令集加速加密 — 自研 TLS 调度引擎，利用 CPU 原生 AES-NI / AVX-512 指令集，流水线批处理加解密，单包开销 <0.3μs，加密几乎不吃性能
全链路背压传导 (Backpressure Propagation) — 多跳节点间自动速率协商，中间节点 CPU 开销恒定 O(1)，加再多跳带宽不掉
自研加密引擎 — 握手阶段一次验证，后续数据转发零认证开销，安全与性能兼得

多跳损耗分析

核心指标：每增加一跳的带宽衰减百分比。Iris 的 zero-copy relay + io::copy 架构实现了近乎零损耗的多跳转发。

每跳带宽衰减率对比
越低越好 — Iris 在加密/非加密场景下均实现 <1% 的多跳损耗

Iris 多跳无损耗

3-hop 加密链路仅衰减 0.7%，得益于 zero-copy relay 架构和自研加密引擎的流水线批处理设计。

比肩内核级方案

非加密场景下 Iris 吞吐达到 nftables 的 99% 水平，作为用户态方案已接近内核态 DNAT 的理论上限。

加密性能领先

加密场景下 Iris 吞吐为 nftables+stunnel 的 95%，但提供完整的 mTLS 双向认证 + 集群管理能力。

测试方法：GCP n2-standard-4 (4 vCPU, 16GB, Intel Cascade Lake, gVNIC 10Gbps) × 6 台，同区域 us-central1-a。iperf3 -P8 -t30 -O2，每组跑 3 次取中位数。加密统一 TLS 1.3 AES-256-GCM。Iris 版本 v0.9.2 (aws-lc-rs)，gost v3.0.0-rc10，nftables v1.0.9 + stunnel 5.72。

结论：Iris 非加密性能比肩 nftables（内核态），优于 gost 约 10-26%；加密性能略低于 nftables+stunnel 约 5%，优于 gost 15-41%；多跳场景下 Iris 衰减率 <1%，gost 衰减 13-19%。
