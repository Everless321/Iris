三方架构定位

不同层、不同抽象。技术对比前先看清楚各自的设计取舍。

nftablesLinux kernel

netfilter / DNAT / 包级重写
  • 内核态包处理，无用户态拷贝
  • μs 级延迟，接近 NIC 线速
  • 单机一跳，多跳需每节点手动配规则
  • 无控制面，无健康检查，无集群
  • 无应用层加密

gostuserland L7

Go 多协议代理 (HTTP/SOCKS/SS/Trojan)
  • 用户态 socket 读写 + chain 链式转发
  • 协议层极丰富（几十种）
  • 静态配置（yaml/CLI），无热加载
  • 无集群 / 故障切换（需外部）
  • 默认明文，需手动配 mTLS

Irisuserland L4 + cluster

Rust 分布式调度平台 (master / node)
  • 每节点强制 mTLS + QUIC datagram (UDP)
  • N-hop 链路 + 每跳节点组 LB + failover
  • master 控制面，动态下发 forward 规则
  • 周期健康探测 + Prometheus / SLA
  • L4 透传（应用层协议透明）

同区域吞吐（us-central1-a，RTT 0.3ms）

同 zone 内 0.3ms RTT，TCP 不受 BDP 限制 → 直接看协议栈 / 数据面开销。NIC 上限 10 Gbps。

TCP 单流吞吐 (iperf3 -P 1, 20s)
单条 TCP 流极限速度。跳数越多衰减越明显 — 体现每跳的实际转发开销。
TCP 多流吞吐 (iperf3 -P 8, 20s)
8 条并发 TCP 流总吞吐。多流能撑满 NIC，更接近真实业务场景。
跳数衰减曲线 (TCP -P 1)
每加一跳的吞吐损耗 — Iris 多跳衰减最大，但每跳含完整 mTLS+rustls
UDP 1Gbps 丢包率
Iris 多跳全部 0 丢包 — QUIC datagram 主动 backpressure 而非 kernel silent drop

跨区域吞吐（us-central1 → asia-east1，RTT 160ms）

高 RTT 下 TCP 单流被带宽延迟乘积（BDP）卡死。这种场景多流 + 链路 relay 价值会被掩盖；用来对比"哪个工具加 relay 的额外开销最小"。

跨太平洋 TCP 吞吐对比
RTT 160ms 下，单流被 TCP 拥塞窗口卡在 ~120 Mbps；多流（P8）才能撑到 ~830 Mbps
RTT 矩阵 (uc1 出发, ping 平均)
跨大洲 GCP 内网延迟基线
跨区域 relay 额外开销
Iris 加 relay 反而吞吐更高 — 因为绕路时 CWND ramp 更早达到稳态

结论 / 选型推荐

没有"最好"，只有"最适合场景"。三方在不同维度各有最优位。

用 nftables 的场景

单机端口映射 / 简单 DNAT / 防火墙规则。同主机 latency 敏感场景（数据库 proxy、本地 socket bridge）。要的是 μs 级延迟 + kernel 路径稳定 + 零运维。不要用它做多机集群转发。

用 gost 的场景

需要 L7 协议丰富度的中等规模代理（ss / trojan / vless 多协议混用）。静态配置可接受、不需要集群调度 / 故障切换 / SLA。注意：UDP forward 配置 quirky，本测试中未跑通；多跳衰减最小但默认明文。

用 Iris 的场景

多节点协同的转发集群 + 全链路 mTLS + 动态规则 + 故障自动切换。SLA 要求 + 跨区域 + 节点池容灾。优势：UDP 0% 丢包（QUIC datagram）、跨区域 ~99% baseline、Web UI 加规则即生效。短板：同区域多跳 TCP P1 衰减大（每跳 rustls 加密成本），高频小流不友好。

叠加使用

三方不冲突。常见组合：节点上跑 gost/xray 作 L7 协议层，Iris 做集群调度 + 故障切换，nftables 做节点入口 ratelimit / DDoS 防护。每层做自己最擅长的事。

测试边界说明： gost UDP forward 因配置语法 quirk 未跑通（standard -L udp:// + iperf3 control message 兼容性问题）； 跨区域 nftables 多跳无意义（DNAT 是单机概念，跨机需要在每个节点逐个配规则，不在本测对比范围）； Iris 多跳同区域吞吐受 rustls 加密开销影响，跨区域因 BDP 限制反而看不到明显劣势； 所有 TCP 测试 iperf3 -t 20 -O 2（前 2 秒预热不计入）；UDP 用 -b 1G / 500M，避免触发 quinn datagram 主动 drop（参考 Phase 9c 实测）； 每组单次采样 — 不是 3 次取平均，单次抖动 ±5% 在可接受范围。
