# 多 target 支持（LB + failover）

## 背景
用户需要在一条转发链路里配多个最终目标地址，按策略分流；某 target 不可达自动 failover 到下一个。和 hop 多节点同款语义。

## 实施
| 层 | 文件 | 改动 |
|---|---|---|
| proto | `crates/proto/proto/control.proto` | +TargetEndpoint，TunnelHeader 和 ForwardRule 增加 `repeated targets` + `target_strategy`，旧 `target` 标记 deprecated 留作过渡 |
| migration | `crates/master/migrations/0007_multi_target.sql` | 新列 `target_strategy DEFAULT 'weighted'`；UPDATE 把 `target` 单字符串转 JSON `[{"addr":...,"weight":1}]` |
| master | `crates/master/src/models.rs` | `Forward` 字段 `target: String` → `targets: Vec<TargetEndpoint> + target_strategy: String`；`ForwardCreate.normalized_targets()` 兼容老格式 |
| master | `crates/master/src/api.rs` | create/update 校验 + 写 JSON；`test_forward` last_hop × targets 笛卡尔积；TestRequest 兼容老单串 |
| master | `crates/master/src/main.rs` | SyncConfig 下发 targets[] 和 target_strategy，同时填 legacy target 给过渡期老节点 |
| node | `crates/node/src/dataplane.rs` | 新增 `TargetRouter`（weighted + source_hash）；出口选 + failover；entry/relay 传 targets[] |
| node | `crates/node/src/forward.rs` | 单跳入口也支持多 target + failover |
| node | `crates/node/src/main.rs` | 从 ForwardRule 取 targets/strategy，传给入口循环 |
| api types | `web/src/lib/api.ts` | +`TargetEndpoint`，`Forward.targets/target_strategy` |
| UI | `web/src/pages/TopologyEditor.tsx` | 顶栏砍掉「目标地址」字段；终点节点摘要显示 N 个 / 策略；点击 → Drawer 编辑策略 + 目标列表（addr + weight） |
| UI | `web/src/pages/Forwards.tsx` + `Dashboard.tsx` | 列表/卡片显示 `targets[0].addr +N` 折叠摘要 |

## 数据迁移
现有 forward 行启动时由 `0007_multi_target.sql` 自动 UPDATE：
- `target = "1.2.3.4:443"` → `target = '[{"addr":"1.2.3.4:443","weight":1}]'`
- 新增 `target_strategy = "weighted"`（默认）

对用户无感。

## 验证（计划）
1. rsync 源码到 nosla → cargo build musl
2. systemctl restart zhuanfa-master（迁移自动跑）
3. pull 新 zhuanfa-node → 4 节点 base64 推送 + systemctl restart
4. 浏览器 http://<MASTER_HOST>:7080 → 编辑现有 forward 看 targets 自动迁移
5. 配多 target 链路 → 测试链路 → 看每条 last_hop_node × target_addr 的延迟

## 取舍
- **不是滚动升级**：master 写新格式，老节点收到 `target=targets[0].addr` 但其余 target 看不到 → 需要同步重启 master + 所有节点
- **least_conn / latency 策略对 targets 退化为 weighted**：targets 维度没有可靠的全局连接计数/探针数据，回退到加权 RR
- **TunnelHeader.target 字段号保留**：proto deprecated 但仍然填首 target，便于过渡
