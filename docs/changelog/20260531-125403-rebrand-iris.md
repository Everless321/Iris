## 部署迁移流程（prod 用）

每个 prod 节点跑 `scripts/migrate-zhuanfa-to-iris.sh`：

1. `systemctl stop zhuanfa-{master,node}.service`
2. `mv /opt/zhuanfa /opt/iris`
3. `mv /opt/iris/data/zhuanfa.db /opt/iris/data/iris.db`
4. 删旧 cert（强制重签）：`rm /opt/iris/certs/{server,server-key,client,client-key}.pem` + `rm -f /opt/iris/certs/.server-cert-version`
5. master：启动 iris-master → ensure_dev_certs 自动签 iris-* CN
6. node：删旧 enrollment，重新走 `/api/nodes/enroll` 拿新 cert
7. systemd unit 改名启用 → `systemctl enable iris-master/node.service`
8. 清旧 unit：`rm /etc/systemd/system/zhuanfa-*.service`

## 滚动顺序

1. CI build iris artifact
2. 先迁移 1 个节点验证完整链路
3. 批量推 + 重启
4. 最后切 master + 全节点改 env IRIS_MASTER
